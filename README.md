# Career Path Finder

Web app with two modes:
- **Path to a career** — pick a role and get a roadmap
- **Career from questions** — short quiz that recommends a path

## Live site

GitHub Pages (static): after deploy, open the Pages URL from the repo Settings.

## Run locally (Flask)

```bash
pip install -r requirements.txt
python app.py
```

Open http://127.0.0.1:5000
